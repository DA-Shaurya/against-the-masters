Against the Masters

Ten neural networks, each trained on world champions' recorded games. Dual Engine: Classical Alpha-Beta vs Neural MCTS.
Classical Search — each champion is a small convolutional network trained by imitation. Alpha-Beta search looks several moves ahead (material + positional evaluation with quiescence search) while the champion's network shapes their personality.

Neural MCTS — a dual-head policy/value network trained on all champions combined. Moves are chosen using Monte Carlo Tree Search (PUCT formula $C_{PUCT}=1.5$) with exact terminal state handling and leaf expansion.

Opening Book — grandmaster theory moves are played instantly (0 ms) before running search engines.
